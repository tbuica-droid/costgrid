How it works

Three steps to the real cost of each job.

Step 1

Connect OpenAI or Claude

Add an admin key, or drop in the usage file you can download from OpenAI or Claude, and CostGrid imports your last 90 days. The key goes into your Mac's Keychain, and if you give it an expiry date, CostGrid stops using it then. Then say which agent uses each key.

Step 2

Tell it which jobs worked

CostGrid now estimates which jobs finished from how each agent behaves: asked again soon after, handed to a person, or ended in an error. These are estimates; a one-line report from your software makes them exact. Works for agents that send requests through CostGrid.

Step 3

See the real cost per job

Failed and retried attempts are charged to the jobs that worked. Each agent gets one plain sentence: steady, mostly failing, unpredictable, or spending with nothing finished. Add how long a person takes and it compares the two. All figures are indicative.

Privacy and key safety

Your data stays on your computer.

Runs on your computer

CostGrid is a Mac app. It works out your costs on your own machine, not on our servers.

Never keeps prompts or AI answers

To notice when the same job is asked again, CostGrid turns the first message of each job into a one-way code on your computer. The words are never saved, the code can't be turned back into them, it never leaves your computer, and it's deleted with your other call records. You can turn this off in Settings.

Keys locked with your Mac's Keychain

Your AI keys are stored encrypted, and the key that unlocks them is kept in the Keychain, where macOS keeps your saved passwords. Your keys are only ever sent to OpenAI or Anthropic, never to us. An admin key you connect goes straight into the Keychain, never into CostGrid's own files, and CostGrid stops using it on the expiry date you chose.

Nothing leaves unless you choose

Nothing is sent from your computer unless you turn it on. With View and control, pausing a key sends Anthropic only that key's id and whether to turn it off or on, and the app shows you exactly that before you press anything.

One key per agent, with an expiry date

We recommend it. You see each agent's cost on its own, you can switch one off without touching the others, and a key with an expiry date stops working on its own.

What this protects against

Your keys aren't sitting readable in plain files, settings or code, and a copied CostGrid folder holds only encrypted keys it can't unlock on another Mac. It can't protect against malware already running on the same Mac; that is out of scope.

FAQ

Straight answers.

Does it read my data?

CostGrid never stores or sends your prompts, your customers' messages or the AI's answers. It saves usage records and, if job matching is on, a one-way code made from each job's first message.

Does it stop hallucinations?

No. CostGrid does not detect hallucinations or check whether an answer is right. It shows what failed and re-run attempts cost you, so you can see which agents waste the most money and fix those first.

Do I need to be technical?

No. Download the app and connect OpenAI or Claude. If a freelancer or someone else set up your AI, CostGrid writes a message you can send them, asking for what it needs.

What does it work with?

OpenAI and Claude today, including agents built in tools like n8n, as long as they run on your own OpenAI or Claude account. To read usage directly, CostGrid needs a key made by someone with an admin or owner role on that account. Without one, drop in the usage file that a developer or billing user can download.

Is there a Windows version?

It's coming. CostGrid is Mac only today.

Is it open source?

No, it's source-available. You can read the code under the Functional Source License (FSL-1.1-ALv2), and each version becomes available under the Apache 2.0 licence two years after its release. The LCSO method behind the numbers is published under CC BY 4.0, so anyone can use it with credit.
