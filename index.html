Integration

Three small changes, none to your code.

01

Point the base URL

Swap one environment variable, or pass it directly to the SDK client. Streaming and tool calls pass through untouched.

step 01 
$ ANTHROPIC_BASE_URL=http://127.0.0.1:8787
02

Tag the traffic

Two optional headers assign spend to an agent and a department. Calls with neither are still measured, just marked unassigned.

step 02 
$ -H 'x-costgrid-agent: chat-bot'
$ -H 'x-costgrid-department: Support'
03

Set the rules

Budgets, model fallbacks and deny lists — one CLI command each, and every change lands in the audit log.

step 03 
$ costgrid policy budget dept:Engineering 500.00 \
  --fallback claude-haiku-4-5

    Technical guarantees

    Measured, not marketed.

    Agent → tool reach, with deny policy

    CostGrid records which agent called which tool, and refuses calls outside the allow list at the proxy — before a token is spent.

    Latency overhead, checked against a null proxy

    A provider call takes 500ms to several seconds. Comparing direct against through-CostGrid would measure our work and the cost of adding any process to the path at once, so the benchmark also runs a proxy that forwards bytes and does nothing else — that's the floor, and these numbers are what CostGrid costs on top of it.

    Measured on a local stubp50p99
    Round trip, 1 request in flight1.2 ms2 ms
    Time to first byte, streaming0.8 ms1.6 ms
    Round trip, 10 in flight1.3 ms4 ms
    50 in flightNot yet published — see below

    High concurrency isn't published because on one machine the load generator, the proxy and the provider compete for the same cores, and the noise is larger than the thing being measured. We'd rather leave it empty than fill it with a number your own load test would contradict. Run it yourself — one command, no account: git clone … && npm install && npm run bench.

    Fail-closed by default: when a cap is hit, the request is rejected with HTTP 403 before it reaches the provider, and the attempt is recorded either way.

    Pricing

    Flat rate. 0% of your AI bill.

    Cost tools that take a percentage of spend get paid more when you spend more. Ours doesn't. The price is the price, whether you burn $2k or $200k a month.

          modules covering price decay, routing, volume, spend, seat pricing and EBITDA impact,
          driven from a single assumptions sheet. The routing maths in the product is that model.
          The difference is that the product measures your real numbers instead of assuming them.
