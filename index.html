How it works

Three steps, no code to rewrite.

  1. Run CostGrid beside your agents

    On a Mac, install the app; it accepts connections from that Mac only. On a server, run the gateway with Docker or Node.js.

  2. Point each agent at it

    Set the OpenAI or Anthropic base URL to CostGrid and give the agent its CostGrid key. The SDK and prompts stay as they are.

  3. Turn on savings

    CostGrid lists the savings your traffic supports. Start one as a dry run, check the figure, then switch it on.

# your agent's environment
ANTHROPIC_BASE_URL=http://127.0.0.1:8787OPENAI_BASE_URL=http://127.0.0.1:8787/v1
# the agent's CostGrid key, in place of the provider key
ANTHROPIC_API_KEY=cg_live_…
OPENAI_API_KEY=cg_live_…
# on the server, from the CostGrid repository
COSTGRID_HOST=0.0.0.0 npm run gateway

# in each agent's environment
ANTHROPIC_BASE_URL=http://costgrid.internal:8787OPENAI_BASE_URL=http://costgrid.internal:8787/v1

Questions

Common questions.

Anything else: sign in and ask, or read the code on GitHub.

Where does CostGrid run?

On your Mac as a desktop app, or on your own server with Docker or Node.js. The Mac app accepts connections from that Mac only, so agents on other machines need a gateway you host.

What changes in my agent?

Its base URL, and its API key, which becomes a CostGrid key. Your OpenAI or Anthropic key stays inside CostGrid. The agent keeps the same SDK, streaming and tool calls included. Claude Code works the same way, through ANTHROPIC_BASE_URL.

How does CostGrid know a job finished?

From how each run ends. Handed to a person, an error, cut off or declined: not finished. Ended normally and not asked again within the agent's window: finished. These figures are marked indicative; one call to POST /v1/costgrid/outcome makes them exact.

What does it cost?

The app and all six savings are free. View and control, priced on request, adds two controls for Claude keys: pausing an agent's keys at Anthropic, and a monthly cap that pauses them for you. Ask for a quote.

Does CostGrid keep my prompts?

No. Requests and answers are read in memory to price them, then discarded, and go only to the provider your agent already uses unless you set a rule. Keys stay encrypted in your Mac's Keychain, or in your server's environment. Privacy in full.

What if the gateway stops?

It is kept thin: responses stream through untouched, and a failure to record a cost never breaks a response. If the gateway stops, set the base URL back to OpenAI or Anthropic.

Will savings make answers worse?

A cheaper model is kept only if jobs finish as often. After any change, CostGrid keeps checking, and switches the rule back with an alert if cost rises or fewer jobs finish.

Which providers does it support?

OpenAI and Anthropic, including Claude on Amazon Bedrock and Google Vertex AI.

Is it open source?

The code is public under the Functional Source License (FSL-1.1-ALv2). Each version becomes Apache 2.0 two years after release. Read it on GitHub.
